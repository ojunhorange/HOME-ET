# HOME:ET 자취지수 · 동네 점수 판정

> 통학으로 잃는 시간·체력과 자취에 더 드는 돈을 **원/월**로 맞춰 동네마다 비교한다.
> 같은 부등식을 정시처럼 **내 점수(자취지수) vs 동네 점수(커트라인)** 로도 보여 준다.
> 코드: `lib/calc.ts` `judge()` · 학교 단위 판정 `lib/app-state.ts` `judgeSchool()` · 검증 `node scripts/check-scoring.mts`
> 원안: `score_migration.md` (백분위 F와 커트라인 아이디어). 이 문서는 원안에 비용 포함, 환승 계수, 동네별 실제 통학, 슬라이더로 움직이는 점수를 반영한 버전이다.

## 1. 입력

| 기호 | 의미 | 출처 |
|---|---|---|
| t₀, n₀, m₀ | 본가 → 학교 편도(분), 환승 수, 하루 왕복 교통비 | 사용자 입력 (Google 경로로 미리 채움) |
| D | 월 등교일 = 주당 등교일 × 4.3 | 사용자 입력 |
| s_m, s_t, s_s | 돈·시간·체력 가치관 (−3 ~ +3) | Gemini 분석 → 리포트 슬라이더 |
| T_d, n_d, m_d | 동네 → 학교 편도, 환승 수, 왕복 교통비 | Routes 캐시 `data/school-commute.json` (도보는 거리로 어림, 환승 0, 교통비 0 / 그 외 3,000원) |
| R_d | 동네 환산 월세 중앙값 (거래별 월세 + 보증금 × 3.5% ÷ 12 의 중앙값) | 국토부 실거래가 1년 `data/school-dongs.json` `median` |
| M, L, I | 관리비 6만, 추가 생활비 15만, 이사·가구가전 54만 + 중개보수 법정 상한 | 가정값 (리포트에서 생활비·초기 비용·보증금 수정 가능) |

## 2. 식

```
f(n) = min(0.5, 0.15 + 0.1·n)                                       피로 계수
k(n) = v · c · ( 1.06^(s_t − s_m) + 1.06^(s_s − s_m) · f(n) )         환승 n번 통학 1시간의 손해 (원/시간)
       v = 10,320 (2026 최저시급), c = 1.35 (기본 시간 가중치)

되찾는 가치 V_d = 2D/60 · ( k(n₀)·t₀ − k(n_d)·T_d ) + D·(m₀ − m_d)
더 드는 돈   E_d = R_d + M + L + I/24
판정         V_d ≥ E_d → 그 동네 추천.   학교 주변 동네 중 한 곳이라도 통과하면 ② "자취 추천"
월세 상한    cap_d = V_d − M − L − I/24        (환산 월세 기준, ③ 화면)
```

- 가치관은 돈과의 차이만 의미가 있어요. 한 칸에 6%이고, 6칸 차이가 나면 1.42배예요.
- 중개보수는 동네 월세 중앙값 기준으로 계산해요. 상한 월세 기준으로 다시 풀어도 차이는 수천 원이에요.

## 3. 점수: 자취지수와 동네 점수

양변을 "가치관 보통일 때 본가 통학 1시간의 손해" `k₀ = v·c·(1 + f(n₀))`로 나누면, 원 단위 비교가 통학시간(분) 비교로 바뀌어요.

```
체감 통학시간  t̃   = t₀ · (1.06^(s_t−s_m) + 1.06^(s_s−s_m)·f(n₀)) / (1 + f(n₀))
필요 통학시간  t*_d = T_d · (1.06^(s_t−s_m) + 1.06^(s_s−s_m)·f(n_d)) / (1 + f(n₀))
                    + 60 · (E_d − D(m₀ − m_d)) / (2D · k₀)

자취지수  = F(t̃)        (동네와 무관한 하나의 점수, 슬라이더를 움직이면 바뀜)
동네 점수 = F(t*_d)      (주로 동네 시세·비용이 정함, 슬라이더는 남는 통학 항만 조금 움직임)
t̃ ≥ t*_d  ⇔  V_d ≥ E_d
```

- 판정은 원 단위 `V ≥ E`로 해요. F가 0분 이하, 240분 이상에서 평평해서, 백분위끼리 비교하면 경계에서 동점이 생길 수 있기 때문이에요.

### F: 통학시간 누적분포
- 출처: 2010년 인크루트 대학생 745명(기숙사생 제외) 통학시간 설문

## 4. 자취 1시간 vs 통학 1시간 (같은 부등식)

```
되찾는 시간      H_d = 2D·(t₀ − T_d)/60
내 1시간의 가치  = (V_d − D(m₀ − m_d)) / H_d
되사는 가격      = (E_d − D(m₀ − m_d)) / H_d
가치 ≥ 가격  ⇔  V_d ≥ E_d  ⇔  자취지수 ≥ 동네 점수     (H_d > 0 일 때)
```

- 손해가 통학시간에 비례해서(x(T) 곡선을 없앰), 1시간의 가치가 통학 길이와 무관한 원/시간이 돼요.
- 동네마다 T_d와 n_d가 달라서 값도 동네마다 조금씩 달라요.
  - ② 리포트는 여유(V − E)가 가장 큰 동네 기준으로 보여 줘요.
  - ③ 월세 추천은 고른 동네 기준으로 보여 줘요.

## 5. 검증 (본가 환승 2, 왕복 4,500원, 주 4일)
- 표의 숫자는 학교별로 추천되는 동네 수(5곳 중)예요.
- 의도 표시(✓) 중 앞의 세 줄은 `scripts/check-scoring.mts`의 assert로 고정돼 있어요.

| 편도 · 가치관 | 고려 | 연세 | 서울 | 한양 | 건국 | 경희 | 의도 |
|---|---|---|---|---|---|---|---|
| 70분 보통 | 0 | 0 | 0 | 0 | 0 | 0 | 재고 ✓ |
| 85분 보통 | 4 | 1 | 1 | 4 | 1 | 4 | 싼 동네는 추천 ✓ |
| 120분 보통 | 5 | 5 | 5 | 5 | 5 | 5 | 60만 이하 전부 추천 ✓ |
| 85분 돈 +3 · 시간 −3 | 0 | 0 | 0 | 0 | 0 | 0 | |
| 85분 시간 +3 · 체력 +3 | 5 | 5 | 2 | 5 | 5 | 5 | |
| 120분 돈 +3 · 시간 −3 | 5 | 4 | 2 | 5 | 4 | 5 | |

**c = 1.35를 고른 이유**
- 비용(약 25만/월)을 넣으면 c = 1.0에서는 85분에도 추천이 0곳이에요.
- c = 1.3이면 서울대가 85분에 0곳이에요.
- c = 1.35는 세 가지 의도를 모두 만족하는 가장 작은 값이에요.

## 6. 한계 · 확장
- **F의 출처:** 2010년 설문이고 표본이 745명이에요. 직접 설문을 모으는 것이 확장 과제예요.
  - 판정은 원 단위라서, F가 바뀌어도 추천 결과는 바뀌지 않아요. 바뀌는 건 표시되는 점수뿐이에요.
- **가정값:** 관리비와 생활비는 가정값이에요.
- **동네 통학:** 동네 → 학교 통학은 동 중심 좌표 기준이에요. 동이 넓으면 실제와 차이가 있어요.
